Why do we need RAG?

Direct LLM Query (no context)

User: "What time is it?"
LLM: "It's 12:42 on June 14 2023..."

RAG Query

User: "What time is it?"
System: "Answer the user's question, given that the current time is 2:30 PM"
LLM: "The current time is 2:30 PM"

What is Retrieval-Augmented Generation?

  • Retrieval: Find relevant content from the knowledge base
  • Generation: Use that content to augment the prompt

Retrieval - Step 1

  • Embed all KB topics ahead of time
  • Store embeddings in a vector db (we use RedisDB)

How Metrics Are Written (Part 3)

U: Why is Ada the best cat in the whole world?
S: Because of her cute face and her adorable personality
  1. Retrieve closest topic for user's input (if score < threshold)
    • (ada-the-bengal-cat, 0.11)
    • (cat-breeds-general, 0.44)
    • (ada-lovelace, 0.68)
  2. Retrieve closest topic for agent's response (if score < threshold)
    • (cat-personality-traits, 0.29)
    • (cat-cuteness, 0.33)
    • (ada-lovelace, 0.77)
  3. Write QA metric based on retrieved topic
    • Topic: ada-the-bengal-cat → QA metric written
